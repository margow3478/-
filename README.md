# 🧨 Сапёр (веб-приложение)

Учебный проект классического сапёра на **HTML/CSS/Vanilla JS**.

## Возможности
- Новая игра
- Сложности: easy / medium / hard
- Открытие клеток и установка флагов (ПКМ)
- Авто-открытие пустых зон
- Таймер
- Рекорды в `localStorage` (с безопасным fallback, если storage недоступен)

## Структура
```
src/
  logic/    # игровая логика (для тестов и архитектуры)
  state/    # состояние игры
  storage/  # сохранение рекордов
  ui/       # рендеринг интерфейса
browserApp.js # браузерная сборка без модулей (гарантированный запуск)
```

## Запуск
### Вариант 1 (самый простой)
Просто откройте `index.html` в браузере.

### Вариант 2
Запустите локальный сервер:
```bash
python3 -m http.server 4173
```
и откройте `http://localhost:4173`.
