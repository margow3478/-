# 🧨 Сапёр (веб-приложение)

Учебный проект классического сапёра на **HTML/CSS/Vanilla JS**.

## Возможности
- Новая игра
- Сложности: easy / medium / hard
- Открытие клеток и установка флагов (ПКМ)
- Авто-открытие пустых зон
- Таймер
- Рекорды в `localStorage`

## Структура
```
src/
  logic/    # игровая логика
  state/    # состояние игры
  storage/  # сохранение рекордов
  ui/       # рендеринг интерфейса
```

## Запуск
Откройте `index.html` в браузере.

## Тесты
```bash
npm test
```
